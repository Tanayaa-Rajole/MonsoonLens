# Data

Real datasets are **not committed** to Git (see `.gitignore`).

| Folder | Purpose |
|---|---|
| `raw/` | Original downloaded files, never edited |
| `processed/` | Cleaned files produced by `src/preprocessing.py` |

## Current status

No real dataset has been added yet. The app uses **synthetic sample data**
generated by `src/sample_data.py`.

## Intended sources

IMD (India Meteorological Department), India-WRIS and CHIRPS. Coverage,
resolution and licence terms will be recorded here after acquisition.

## CSV format expected by `src/data_loader.py`

```csv
date,district,rainfall_mm
2022-06-01,Pune,4.2
2022-06-02,Pune,0.0
```

Convert any downloaded dataset to these three columns, save it in `data/raw/`,
then train with: `python -m src.train --data data/raw/yourfile.csv`
